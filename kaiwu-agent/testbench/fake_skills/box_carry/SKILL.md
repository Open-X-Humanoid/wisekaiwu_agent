# 搬箱子（工厂工艺）
完整流程：**查起始坐标 → 导航 → 初始化 → 视觉扫描桌面 → 抓起箱子 → 导航到目的地 → 放下**。

## ⭐ 关键前置条件：状态检查（STEP 0）
- **手中不能有物品** — 否则失败"请先放下当前持物再搬箱子"。

## Steps
完整 7 步流程。用户可能让你跑完整流程，也可能只让你执行某一步，请根据指令区分。

1. **查桌子/起始点坐标**：`spatial_memory_query_vec(obj_cn_name="货架")` 或 `obj_cn_name="桌子"` — 获取箱子的起始位置。
   - 如果用户没说从哪里搬，默认查"桌子"，从桌子上面开始搬运。
2. **导航到起始点**：`move(dst_point={"x":..., "y":..., "yaw":...})` — 移动到桌面附近。
3. **初始化机器人**：`initialize(init_pose={"x":..., "y":..., "yaw":...})` — 初始化位姿状态。
4. **扫描箱子**：`scan_table_with_box` — 视觉算法扫桌面，返回箱子位置。
   - 失败 → 重试 1 次；仍失败 → 报告"未扫到箱子"，结束。
5. **抓起箱子**：`pick_up_box` — 抓起视野中的箱子。
   - 失败 → 重试 1 次；仍失败 → 报告"抓取失败"，结束。
6. **导航到目的地**：先 `spatial_memory_query_vec(obj_cn_name=目的地)` 拿坐标，再 `move(dst_point=...)` 过去。
7. **放下箱子**：`put_box_to_table` — 在目的地桌面放下。
   - 失败 → 重试 1 次；仍失败 → 报告"放置失败"，结束。

**注意**：每次调用工具前都必须要说明当前正在执行的动作，比如：
- 调用spatial_memory_query_vec前说"我先查一下桌子在哪"
- 调用move前说"找到桌子了，我过去"
- 调用scan_table_with_box前说"到了，我扫一下桌面上的箱子"
- 调用pick_up_box前说"扫到箱子了，我抓起来"
- 调用put_box_to_table前说"搬到地方了，我把箱子放下"
