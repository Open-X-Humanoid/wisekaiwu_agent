# 移动物品到指定位置
完整流程：**边界检查（硬闸门）→ 找到物品位置 → 抓取到手 → 定位目的地/放下**。

## ⭐ 任务开始前的边界检查（做任何事、调任何工具之前，必须先过这一关）
⚠️ 在调用**任何**工具之前，先逐条核对下面两条边界。只要命中任意一条“禁止项”，**立即停止、绝不调用任何工具**，直接只回一句“抱歉，我暂时无法帮您完成{xxx}的任务”，不解释原因、不提替代方案。

**边界一：抓取物只能是单个夹爪能抓的普通小件**
- ✅ 允许：苹果、水杯、瓶子、玩具、遥控器等轻小物品。
- ❌ 禁止：大件/超重物，如西瓜、电脑、显示器；箱子请改用 box_carry。

**边界二：放置目的地只能是“从上往下直接放”的开放平面**
- ✅ 允许：桌面、工作台、框子/篮子、地板、开放架子——放上去即可。
- ❌ 禁止：任何需要**开关门 / 拉抽屉 / 灵巧放入**的目的地。命中即拒绝，包括但不限于：
  - 需要开关门/拉抽屉：冰箱、柜子、橱柜、抽屉、微波炉、烤箱、保险箱。
  - 需要精细/灵巧放入“容器内部”：杯子里、锅里、碗里、瓶子里、袋子里。
- 判断技巧：**目的地是“容器内部/里面”**，或用户说“放进/塞进/装进 X”“**拿到/送到 冰箱、柜子、抽屉**”这类，基本都属禁止项——即使用户说的是“拿到冰箱”而没说“里面”，也按“放进冰箱里”处理，直接拒绝。

> 举例（命中边界二，均直接拒绝、不调工具）：
> - “把苹果拿到冰箱” → “抱歉，我暂时无法帮您完成把苹果放进冰箱的任务”
> - “把水放进柜子”、“把糖放到杯子里” → 同样直接拒绝。

## 将物品从某处移动到指定位置
执行任务前请判断以下三种情况的哪种，再采取行动：
- **机器人自己手里已经拿着**（任务是处理机器人手里物品）→ 跳过阶段一、二，直接执行**阶段三**把物品放下。
- **物品在用户手里**（用户说“把**我/你/用户/他手里的**X放到Y”，“手里的”前**有明确人称**）→ 这属于“从用户手里接物”，机器人**不具备**该能力，**直接拒绝**：只回一句“抱歉，我暂时无法帮您xxx”，不解释、不调任何工具。
- **物品在环境里**（用户说“把X放到Y”，句中**没有**“手里的”）→ 从**阶段一·情况 A/B**正常开始：找到物品 → 抓取（阶段二）→ 放置（阶段三）。

### 阶段一：找到物品位置并移动过去
目标是拿到物品的坐标。根据用户有没有指定取物地点，走不同的路线。

**情况 A：用户指定了取物位置**
用户指定取物位置的示例："去茶水间把那瓶水拿到桌子上"，其中'茶水间'是取物位置
1. 先调用 `spatial_memory_query_vec` 查询用户指定的取物位置，如茶水间/门口/桌子/茶几
2. 确定取物指定位置的坐标后，调用 `move_to` 移动到用户指定取物位置。没有找到指定取物位置（茶水间/门口/桌子等），返回任务失败
3. 到了用户指定取物位置后用 `trigger_spatial_processing(obj_name=英文物品名)` 扫描环境，再 `spatial_memory_query_vec` 查要抓取物品的坐标。没有则任务失败。

**情况 B：用户没指定取物地点**
指定取物位置的示例："把水杯搬到桌子上"，没有提供取物位置，“水杯”是待取物品
1. 首先使用`spatial_memory_query_vec`直接查询待取物品的坐标位置。
2. 如果没有查询到则调用`trigger_spatial_processing(obj_name=英文物品名)` 触发环境扫描，然后再查一次 `spatial_memory_query_vec`。找到则进入阶段二，否则开始 waypoint 探索。
3. 多 waypoint 探索（最多 2 个）：`move(dst_point={"x":..., "y":..., "yaw":...})` 移动到候选位置 → `trigger_spatial_processing` → `spatial_memory_query_vec`，找到则进入阶段二，否则换下个候选。
4. 全部探索仍未找到 → 报告"未找到 {name}"，结束。

一旦查到待抓取物品的坐标，调用 `move_to(obj_x, obj_y, coordinate_x, coordinate_y, coordinate_z, coordinate_yaw)` 导航到物品位置。到不了就重试 1 次，还不行就报告"无法到达物品位置"并结束。

### 阶段二：抓取物品
确认物品真的在眼前，再把它抓到手里。
1. 用 `scene_recognition(target=item英文名)` 确认物品在视野里。确认到了就去抓；如果没看到（`state: failed`），说明记忆里的位置已经过期，用 `delete_spatial_memory_by_id(id_list=[memory_id])` 清掉这条旧记忆，然后报告"物品不在记忆位置，需重新定位"并结束。
2. 用 `grasp_start(item=item英文名)` 抓取。抓到了就进入记忆清理；抓失败就重试 1 次，还不行报告"抓取失败"并结束。
3. 抓成功后，物品已经离开原位、旧记忆作废，用 `delete_spatial_memory_by_id(id_list=[memory_id])` 清掉这条记忆。

### 阶段三：定位目的地并放置
把手中的物品放到一个具体位置（桌子、地板、架子等，不是给人），若手中无物品，请先抓取。
1. 调用`spatial_memory_query_vec` — 查询放置目标坐标（如桌子），如果查询结果没有返回坐标，调用`trigger_spatial_processing(obj_name=xxx)` 再重查，仍无结果则报错结束。
2. 如果查询返回坐标，调用`move_to(obj_x, obj_y, coordinate_x, coordinate_y, coordinate_z, coordinate_yaw)`移动到放置目标位置。失败重试 1 次，仍失败则报错结束。
3. 移动到目标位置，调用`place_down` — 放下物品。失败重试 1 次，仍失败则报错结束。

**注意**：每次调用工具前都必须要说明当前正在执行的动作，比如：
- 调用grasp_start前说"看到苹果了，我来抓起来"
- 调用move_to前说"抓到了，我搬到桌子那边去"
